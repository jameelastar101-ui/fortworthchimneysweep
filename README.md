# Fort Worth Chimney Sweep (Chimney Sweep Pro)

Static Astro site for fortworthchimneysweep.com, deployed on Netlify from `main`.

- `astro-migration-brief.md` — migration scope, URL inventory, design system, SEO checklist
- `docs/cluster-map.md` — topic clusters, frontmatter values, internal-linking rules
- `CLAUDE.md` — dev-server and tooling instructions for agents

## Commands

| Command           | Action                                                        |
| :---------------- | :------------------------------------------------------------ |
| `npm install`     | Install dependencies                                          |
| `npm run dev`     | Dev server at `localhost:4321` (agents: `astro dev --background`) |
| `npm run build`   | Build to `./dist/` and run the placeholder check              |
| `npm run preview` | Preview the build locally                                     |
